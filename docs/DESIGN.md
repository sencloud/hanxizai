# 设计说明

这份文档记录三件事：从互动长卷《清明上河图》项目（[xianxie6/qingming-riverside](https://github.com/xianxie6/qingming-riverside)）借来的方法，它们在本项目里的落点，以及还没做到的地方。模式本身另存为 Codex 技能 `handscroll-interactive`。

## 一、七条判断

1. **画卷即世界坐标系。** 原作就是地图。横向是一条统一的世界轴，所有图层共用同一个 `x`；分段只用来组织代码，不用来组织观看。
2. **底图静止，图层动。** 绢地、立柱、屏风是静止底板；人物、器物、光、烟、声叠在上面。
3. **素材是生成的分层图，不是程序画。** 程序化矢量人物最多做到"像长卷的一段"，达不到院体工笔的密度。正确路径是：无人的底板 + 逐个生成的人物与陈设 + 矢量遮罩，素材以原作局部为参考，摆回原作的位置。
4. **混合渲染，各司其职。** Canvas 2D 画分明的形体，WebGL 画连续的场；失败必须能回退。
5. **运动绑定真实量，而不是绑定时间。** 走位绑定行程，舞步绑定鼓点，鼓槌绑定蓄力。
6. **氛围是一条全局时间轴。** 由它推演出若干连续量，同时驱动视觉与听觉。
7. **玩家给的是力，不是播放键。** 输入进入状态量，过度用力要付出代价。

## 二、落地

### 原作即版式

`img/` 下的原作全卷（12172×500）是唯一的版式依据。画面从原图 x≈4080 到 10120，`src/layout.js` 用

```text
worldX = (origX − 4080) × 1.8      worldY = origY × 1.8      世界 10872 × 900
```

把它铺成世界坐标。`ITEMS` 里每件素材记的是**原图上的框** `[x0, y0, x1, y1]`，而不是世界坐标，所以对照原作调版式时可以直接量图。摆放规则只有一条：缩放 `s = 框高 × 1.8 / 素材内容高`，脚踩框的下沿，水平居中；`z` 默认取框下沿（越靠下越在前），床榻屏风等大件用显式 `z` 压到后面。

`scripts/compose_layout.py` 用与运行时完全相同的规则把素材合成到绢色地上，与原作上下对照输出 `docs/compare-*.jpg`。版式的每一次调整都先在这里过一遍。

### 素材流水线

`scripts/build_figures.py` 把 42 张生成的白底立绘做成 47 件运行时素材：

| 步骤 | 做法 | 为什么 |
| --- | --- | --- |
| 抠底 | 从四边泛洪去掉与画框连通的白底；被轮廓围住的纯白空洞另判；边缘按墨线亮度求覆盖率并反解前景色 | 深色绢地上不留白边 |
| 做旧 | 纯白压到约 (226, 205, 166)，高饱和降一档，加极淡的绢纹颗粒与斑驳；随机种子取 `crc32(id)`，每次重建结果一致 | 否则人物贴在旧绢上像剪纸 |
| 分件 | 一张图里并肩站着几个人时按竖线切开（听乐段的三位立客、两位女子） | 每人一个框，能独立摆放和点击 |
| 换色 | 同一张乐女立绘按色相换裙色，得到另一位乐女 | 原作五位乐女里有两对姿势相近，只是衫色不同 |
| 拆层 | 按肤色定位头部，连同 `parts` 多边形（鼓槌、团扇、琵琶女拨弦的右手、洗手的双手、送别时举起的手）剪成独立图层，身体层在挖空处补底 | 点头、击鼓、拨弦、摇扇时露出的是衣料而不是空洞 |
| 矢量遮罩 | 外轮廓多边形写进 `src/figure-atlas.js` | 命中测试、高亮描边、贴图未就绪时的剪影 |

元数据是普通脚本（`HX.figureAtlas`），所以 `file://` 下也能直接加载，不需要 `fetch`。

### 运行时

| 原则 | 本项目的实现 |
| --- | --- |
| 世界坐标 | `scene.computeView()` 是唯一的视口换算；`toWorld()` 让点击、缩放、声场共用同一个坐标。镜头从卷首（右端）开始，`←` 向卷尾前行，自动漫游向左走，到头从卷首重新开卷 |
| 底图静止 | `plate.build()` 一次性画出旧绢、立柱、大屏风与题签，每帧只 `drawImage` 视野内的矩形 |
| 分层与遮挡 | 底图之上，静止陈设、分层器物（鼓架、烛台，`plate.LAYERED`）与人物合成一张列表，按 `z` 排序后绘制；视野外的按框剔除。鼓架立在榻前、烛台立在案前，所以不能进底图 |
| 素材的"活" | `src/sprite.js` 把身体切成 18 条横带，每条按 `lean`（俯仰）、`sway`（下摆随步）、`hem`（裙摆张开）、`chest`（胸廓随呼吸）、`bob` 偏移；每条带用一次切变把上下沿各自对准自己的位移，带与带之间没有台阶。头部另有 `nod`、`look`（转眼望）、`lift`（抬头）；部件绕枢轴转动，并跟随枢轴所在横带的位移。这是参考项目"网格形变 + 部件旋转"的二维简化 |
| 像活人 | `scroll-life.js` 的 `alive()` 是每个人的底子：呼吸约四秒一次、吸短呼长；重心用两层噪声慢慢游移；隔十几秒抬眼一望；身子朝本段的焦点（琵琶、舞者、洗手的主人、乐队、送别的主人）微倾。速度、相位、沉稳程度都由 `hashString(sprite)` 决定，没有两个人同步 |
| 不生硬 | `Director.advance()` 对所有姿态量做临界阻尼弹簧平滑（Unity `SmoothDamp` 的形式），身体慢、头稍快、鼓槌与拨弦的手最快。演出函数可以给出跳变的目标，画面上永远是连续的；自测量出 60 帧下每帧的最大变化 |
| 乐谱驱动 | `src/score.js` 是声音与动作共用的时间线。琵琶女的手 = 琵琶声部的起音包络；舞起之后韩熙载按鼓谱落槌、宾客按掌谱击掌；乐女在句末换气后仰；琴、笛、筚篥、拍板都从同一支旋律派生 |
| 舞者 | 王屋山有两张姿势（背身叉腰 / 扬袖旋裙），用 `match` 共享比例与脚线，在扬袖的一瞬间短暂溶接；旋转阶段按 `cos(phase)` 压扁并翻面 |
| 运动绑定真实量 | 鼓槌：`stick = 0.2·charge − 0.34·hit`，蓄力时抬、落槌时砸；舞步：`phase += dt·(1.4 + force·2.6)`；托盘侍女的走位由行程窗函数给出，回程按真实移动方向翻面 |
| 时间轴编组 | `src/scroll-life.js` 的 `CAST`（取自 `layout.ITEMS` 里带 `life` 的 39 件）+ `STORIES`（每种演出一个纯函数）+ `CYCLES`（周期与错开量）。演出只返回姿态参数，不碰像素 |
| 状态机事件 | `src/dance-event.js`：`approach → call → raise → step → spin → close → record → complete`。鼓点写入 `force`，`force > .85` 记一次过度用力并让舞步变慢；舞到正酣时自动漫游的镜头会停下 |
| 命中 | 先看烛火、鼓面，再按 `z` 从前往后对人物做轮廓点内测试，最后是陈设；前面的人先接住点击 |
| 群体分化 | 每支烛用 `seed(seedId)` 得到自己的熄灭时刻 |
| 氛围 | `src/light.js` 的 `NightClock` + `ambience()` 推演出 `flame / shadow / smoke / warm / still / dawn`。`tint()` 画在整个世界层之上，静止的底图与活动的人物共用同一层着色；香烟的源头吸附在案上执壶的锚点上 |
| 配乐与空间音频 | `src/audio.js` 每帧把乐谱上未来 0.25 秒内的起音换算到音频时钟上提前排好（lookahead scheduling）。五段各有一条总线，按镜头中心到各段的距离交叉淡入（650 世界单位）；笛声与筚篥是常驻发声体，音高与气口跟着乐谱走，并按乐女在画面中的位置计算 `StereoPanner`。第一次用户手势时自动创建 `AudioContext`，页面失焦即静音；声音层出错只让声音停下，不会冻住画面 |
| 看原图 | `src/original.js` + `src/annotations.js`：原图按高度装进视口，拖动带惯性，小地图标出每则批注。批注卡是竖排旧纸，从批注点一侧自右向左展开（`clip-path`），朱线（SVG 路径）连回画上；竖排里的阿拉伯数字换成汉字数码。卡片按阅读方向放在批注点左边，移卷时跟着走，批注点离开视口就收起 |
| 降级 | WebGL → Canvas 香烟；贴图未加载 → 轮廓剪影；`prefers-reduced-motion` → 粒子减量；`#nosmoke` 可直接验证回退路径 |

## 四、取舍与已知不足

- **生成素材不是摹本。** 构图、朝向、衣色按原作，但笔触、面相、衣纹细节是重新生成的，与原作并不逐线相同。素材按原作局部逐件生成，所以没有出现在参考局部里的东西也不会凭空出现。
- **还缺两个小人物。** 原作歇息段床后最左（原图约 x 6929–6984）露出半身的女子、听乐段上方探头的女子还没有生成。
- **大屏风是程序画。** 清吹与歇息之间那架大屏风目前只有素面与边框，没有原作屏心的山水。
- **形变是二维近似。** 横带位移能做出俯仰、摆动与裙摆，但做不出转身；舞者的转身靠两张姿势溶接与翻面。
- **离屏合成多一次全屏拷贝。** 换来的是"氛围统一作用于一切"。低端设备上若成为瓶颈，可把氛围着色烘焙进静止部分。
- **声音是合成音色，不是演奏。** 曲子是为本项目写的五声小曲，不是《六幺》古谱。
- **动作仍是二维的。** 呼吸、俯仰、转眼、拨弦都是形变与部件转动，人物不会离开原作的姿势。
- **批注是导读，不是考证。** 人物身份多据《宣和画谱》与通行说法，凡有异说处写明"相传""一般认为"。

## 五、调试与验证入口

```text
index.html#x=7000&z=0.7      定位到某处（x 是视口左缘的世界坐标）并缩放
index.html#warp=70           把更漏直接推到"香尽"
index.html#nosmoke           强制走 WebGL 回退路径
index.html#t=1               跳过开卷提示
index.html#original          打开时直接看原图
HX.app                       控制台里可以拿到 state、dance、director、bank、sound
HX.original.show('l-limei')  看原图并展开某一则批注
node tests/logic.test.cjs    版式 / 生活时间轴 / 乐谱与动作 / 批注 / 舞曲状态机 / 更漏氛围
python scripts/compose_layout.py   素材按版式合成，与原作上下对照
```
