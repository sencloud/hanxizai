# 素材清单

47 件运行时素材，由 `assets/figures/raw/` 下 42 张生成图经 `scripts/build_figures.py` 加工而来。表中"原图框"是素材在原作全卷（`img/`，12172×500）上占据的范围 `[x0, y0, x1, y1]`，也就是 `src/layout.js` 里的 `box`；生成时用的参考图就是原作上这一框的局部（四周略放宽）。

## 生成方式

每张原料图都以对应的原作局部为参考图生成，提示词按同一个模板写：

```text
参考图是《韩熙载夜宴图》中的一个局部。按参考图重画其中的<人物/陈设>：
朝向、姿态、手势、衣色、冠帽、所持器物与参考图一致；
五代至宋院体工笔重彩，细劲墨线勾勒，平涂设色，衣纹清晰；
完整呈现，从头到脚不裁切；纯白背景，无地面阴影，无绢纹，无印章，无题字，无其他人物。
```

几条约定：

- **白底、无地面。** 背景只留给流水线抠掉；地面与绢纹由底图提供，素材里有的话会和底图打架。
- **一张图一件事。** 同一局部里并肩站立、动作各自独立的几个人，生成在同一张图里（构图关系更准），再由流水线按竖线切开；彼此相拥或交叠的群像保留为一件。
- **能复用就复用。** 姿势相近、只差衫色的乐女，只生成一张，另一位用色相变体得到。
- **原料尺寸** 为 720×1280、864×1152、1152×864 或 1280×720；`build_figures.py` 里的部件多边形与锚点都写原料像素。

## 加工字段

| 字段 | 含义 |
| --- | --- |
| 头层 | 按肤色定位头部并拆成独立图层，可以点头、侧耳；群像、舞者、手与乐器贴着脸的不拆 |
| 部件 | 额外可动的图层与枢轴：`stick` 鼓槌、`fan` 团扇、`hand` 拨弦的右手 / 举起的手、`hands` 洗手的双手 |
| 锚点 | 供光、烟、交互吸附的点：`skin` 鼓面、`bridge`/`nut` 琵琶弦两端、`ewer-a`/`ewer-b` 执壶口 |
| 切片 | 从一张原料里取 `[x0, x1)` 竖条 |
| 换色 | 色相区间 → 目标色相（OpenCV 0..180） |

所有素材都做抠底、做旧与矢量轮廓，表中不再重复。
